讲解要点

  1. 位置错，不是清晰度错。点仍然是一个点，只是像高偏离了理想位置；所以畸变不会让画面发虚。
  2. 三级畸变看视场。相对畸变 q 随视场平方增长，像高偏差 δy′ 随视场三次方增长。
  3. 符号看边缘。边缘放大率小于中心 → 桶形；大于中心 → 枕形；中段桶形、四角枕形 → 胡子形。
  4. 光阑与对称性。光阑位置、镜头前后组的对称性会改变畸变的符号和大小。
  5. 校正靠反演。软件用标定得到的模型把像素映射回理想位置；不是锐化，也不能补回没拍到的视场。

枕形
前 后

光阑在透镜之后：边缘主光线被“送”得更远，四角被拉开——枕形。

01 / 光阑

光阑位置改写主光线

主光线是穿过光阑中心的那条光线。光阑前移或后移，主光线在透镜上的高度随之改变，出射方向也被改写，最终落在像面上的高度就不再等于理想值。

口径不变，像仍然清晰；改变的是“位置”。

02 / 视场

越靠边，错得越多

三级畸变里，像高偏差正比于视场的三次方：δy′ ∝ ω³；换算成相对畸变，就是 q ∝ ω²。所以中心几乎为零，四角最明显。

03 / 对称

对称结构更“直”

前后组近似对称的镜头，畸变会互相抵消，所以标准镜头往往很直；广角镜头前组明显更大、更强，桶形就压不住了。鱼眼则干脆放弃直线投影，换一个超大视场。

对称性是一种“免费的校正”。

理想y₀ = f · tanω
实际y′ = y₀ + δy′
相对畸变q = δy′ / y₀
三级近似q ≈ k₁ω²

标定

拍一张棋盘格或点阵靶标，用已知的直线求出每个视场的实际像高，拟合出 k₁、k₂ 等系数。

02

反演

对输出图像的每个像素，按模型找到它“本来应该在”的输入位置，重采样。直线就回来了。

03

取舍

校正会裁掉或拉伸边缘视场；强畸变下四角还会变软。参数过头，会出现反向畸变。

注意

“校正”不是“锐化”。畸变从来不影响清晰度，它只改变位置。

05

笔记NOTES

带走这页最值得记住的几件事。

公式

一张图记住畸变

理想像高y₀ = f·tanω

实际像高y′ = y₀(1 + q)

相对畸变q = (y′ − y₀) / y₀

径向模型r′ = r(1 + k₁r² + k₂r⁴)

桶形取负、枕形取正。四角是最大视场，也是畸变最容易被看见的地方。

易混

畸变 ≠ 透视变形

广角贴近拍摄时，近大远小和边缘拉伸属于透视投影，不是镜头畸变。判断方法：畸变会把直线弯成弧；透视不会把直线变弯，只会让它们汇聚。

实拍

常见镜头的大致倾向

  • 超广角 14–20mm桶形 −3% ~ −8%
  • 广角 24–28mm桶形 −1% ~ −4%
  • 标准 50mm通常 < 1%
  • 长焦 85–200mm枕形 +1% ~ +3%
  • 鱼眼极强桶形 / 特殊投影
方法

这页的模型边界

本页只讨论径向、单色的几何畸变，忽略切向畸变、色差、彗差等。多项式参数用于教学演示，不能直接当作某支镜头的实测标定结果。

真实校正常用 Brown–Conrady 模型：同时包含 k₁、k₂、k₃ 与切向项 p₁、p₂。

畸变不会让照片变糊，
但它会让直线说谎。
